## 🚀 Key Technical Features

*   **Dual-Channel Communication Engine:** Integrated forms allow users to choose between sending standard asynchronous emails or opening structured chats directly via device native WhatsApp apps using deep links (`whatsapp://`).
*   **Floating WhatsApp Live Chat Widget:** A custom, cleanly decoupled JavaScript widget built to inject a branded support desk pop-up frame natively on the frontend layout.
*   **Fully Clean Architecture:** Complete separation of presentation layouts (`contact.html`) from operational scripts (`contact.js`) to maximize modularity and maintainability.
*   **Modern Responsive Typography & CSS Grid System:** Styled components adapt perfectly to changing mobile, desktop, and tablet viewport dimensions.
