🌍 Overview

Gotiqa Smart Farm is a digital farm management platform developed to help farmers efficiently manage livestock operations while providing investors with transparent insights into farm performance.

The platform focuses on:

- Livestock data management
- Animal health and production monitoring
- Feeding and breeding record tracking
- Weather-aware farm intelligence
- Crowd farming and agricultural investment opportunities

Currently, Gotiqa manages a growing herd of meat goats in Ruai, Kenya, aiming to bridge agriculture and technology for sustainable livestock production.

---

✨ Features

🐐 Animal Management

- Register and manage individual animal profiles
- Track breed, age, weight, gender, and identification records
- Monitor growth and herd statistics

🩺 Health Records

- Record illnesses, treatments, vaccinations, and medications
- Maintain historical veterinary records
- Generate health alerts and improve disease prevention

🌾 Feeding Management

- Log daily feeding schedules
- Monitor feed consumption patterns
- Track nutritional supplementation and feed efficiency

❤️ Breeding Records

- Record mating activities
- Track pregnancy status and expected kidding dates
- Maintain breeding history for genetic improvement

🥛 Production Monitoring

- Track production metrics and farm performance
- Monitor herd productivity trends over time

📊 Farm Dashboard

- Centralized overview of:
  - Total animals
  - Health statistics
  - Feeding activities
  - Production summaries
  - Recent farm activities

🌦 Weather Intelligence

- Real-time weather integration
- Environmental monitoring for improved livestock management
- Supports climate-aware decision making

💰 Crowd Farming Vision

- Transparent livestock investment ecosystem
- Future support for investor dashboards
- Farm growth analytics and investment tracking

🚀 Installation

Clone the repository:

git clone https://github.com/Rohhelion-dev/Gotiqa.git

Navigate into the project:

cd Gotiqa

Install dependencies:

npm install

Run the development server:

npm run dev

Build the application:

npm run build

Deploy to GitHub Pages:

npm run deploy
